# CLAUDE.md — Claude Code Entry Point

## Mission
Complete the CS4032 Software Construction and Design Assignment 01 — CivicPulse as a traceable, secure, production-style engineering repository.

## Read Order — Mandatory
Before doing anything:
1. Read `AGENTS.md`.
2. Read `docs/AI_SESSIONS.md` — one phase at a time, parallel versus handoff work, prompt library.
3. Read `README.md`.
4. Read `docx/ASSIGNMENT.md` — the complete Markdown transcription of the authoritative assignment source.
5. Read `docs/DOCUMENT_INDEX.md` and `docs/PHASE_STATUS.md`.
6. Read `docs/ASSIGNMENT_TRACEABILITY.md`.
7. Read the current phase prompt under `docs/phases/`.
8. Read the linked GitHub Issue and its acceptance criteria.
9. Inspect only the source/config/test files relevant to the issue.
10. Then implement.

## Authority
The supplied assignment is the highest authority. This prompt pack is an execution framework, not a replacement for the assignment.

Never invent:
- a missing requirement,
- an omitted endpoint,
- a schema field,
- a technology restriction,
- a marking criterion,
- or a deadline rule.

If a source is unclear, record the ambiguity in `docs/BLOCKERS.md` and continue only with work that is not dependent on the ambiguity.

## Important
The assignment explicitly states that a clean repository is part of the handover bar: a stranger must be able to clone and run it, and the README must only claim things that can be demonstrated.

Do not silently skip an assignment item because it is inconvenient.
