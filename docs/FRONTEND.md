# Frontend Engineering Contract

Implement only the presentation and interaction responsibilities assigned to the frontend.

Required concerns:
- React 18 + Vite + TypeScript
- typed API client from/checking against OpenAPI
- client validation mirrors server validation
- loading state
- error boundary
- dashboard pagination
- filters
- server-side transition decisions
- 409 error surfaced
- stats `X-Cache`
- runtime configuration without a baked-in API URL
- no secrets in browser bundle
- component tests
